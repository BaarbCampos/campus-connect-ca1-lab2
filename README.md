## Application Description

Campus Connect is a student application developed using Ionic React. It allows students to explore campus events, view event details, search for events, and join or leave activities.

## Features

- Displays four campus events.
- Shows each event's title, location, time, and category.
- Allows users to enter their name and see a personalised greeting.
- Searches events by title.
- Displays a message when no events match the search.
- Allows users to join and leave individual events.
- Displays the total number of joined events.
- Saves joined event IDs in localStorage and restores them after refreshing the page.
- Provides a separate event details page with a Back to Events button.

## Technologies Used

- Ionic Framework
- React
- TypeScript
- React Router
- Browser localStorage
- React useState and useEffect hooks

## How to Run the Application

1. Install Node.js and npm.
2. Open a terminal in the project folder.
3. Run `npm install`.
4. Run `ionic serve`.
5. Open the local URL displayed in the terminal.
